01

Overview

This document covers the complete design system for myuxd.work — the personal portfolio of Mark Young, Senior Product Designer. The system is implemented in vanilla CSS using custom properties (CSS variables) as design tokens. All values are defined in css/styles.css.

The system is built around one principle: content is the star. Every visual decision exists to serve the writing, not compete with it.

Color Tokens

Light Mode [data-theme="light"]

Token Value Usage
--color-bg #FFFFFF Primary background
--color-bg-secondary #F5F5F5 Section bands, card backgrounds
--color-text #111111 Primary body text
--color-text-secondary #555555 Captions, secondary labels, metadata
--color-accent #0066FF CTAs, active states, links, key highlights
--color-border #E0E0E0 Dividers, card borders, table rules
--color-placeholder-bg #C8D0D8 Image placeholder frames

Dark Mode [data-theme="dark"]

Token Value Usage
--color-bg #0D0D0D Primary background
--color-bg-secondary #1A1A1A Section bands, card backgrounds
--color-text #F5F5F5 Primary body text
--color-text-secondary #999999 Captions, secondary labels, metadata
--color-accent #0066FF CTAs, active states, links, key highlights
--color-border #2A2A2A Dividers, card borders, table rules
--color-placeholder-bg #2A2A2A Image placeholder frames
--color-placeholder-text #888888 Placeholder label text

Accent Usage Rules

  • #0066FF is used sparingly — it is a signal, not a coat
  • Applied to: primary buttons, active nav states, link text, card hover borders, key highlight text
  • Never used as a background color on large surfaces
  • Opacity variants not used — full value only

Typography Rules

  • Section labels always uppercase, wide letter-spacing, --color-text-secondary
  • No decorative typefaces — Roboto only
  • Line length capped at approximately 70 characters for body copy
  • Bold (700) used for emphasis within body — never italic

05

Layout

Grid

  • Max content width: 1200px, centered
  • Gutter: clamp(1.5rem, 5vw, 3rem) on left and right
  • Product story card grid: 2 columns on desktop, 1 column on mobile
  • Breakpoint: 768px — below this, all multi-column layouts collapse to single column

Story Page Layout

  • Single column, max-width 760px, centered
  • Section titles: uppercase, 0.7rem, wide tracking, with a 1px top rule in --color-border
  • Each section separated by --space-6 padding
06

Buttons

Primary Button

  • Background: --color-accent (#0066FF)
  • Text: #FFFFFF
  • Font: Roboto Medium, 0.9rem, 0.03em tracking
  • Padding: 12px 28px
  • Border radius: 4px
  • Hover: 10% darker (#0052CC)
  • No shadow

Secondary Button

  • Background: transparent
  • Text: --color-text
  • Border: 1.5px solid --color-border
  • Font: same as primary
  • Padding: 12px 28px
  • Border radius: 4px
  • Hover: border color shifts to --color-accent, text shifts to --color-accent

Button Rules

  • Slight border radius only — never pill shaped
  • Accent color reserved for primary buttons only
  • Never stack more than two buttons side by side
  • Label always uses sentence case with arrow: "Read Story →", "View Live Site →"

Navigation

Structure

  • Nav links: Roboto Medium, 0.85rem, 0.05em tracking
  • Active state: --color-accent

  • No sub-sub-menus — one level of dropdown only
  • Sticky on scroll — fixed to top of viewport

Cards

Product Story Cards (Homepage)

  • Background: --color-bg-secondary
  • Border: 1px solid --color-border
  • Border radius: 4px
  • Padding: 0 (image flush to top, content padded internally at --space-3)
  • Hover: border color shifts to --color-accent
  • Image area: placeholder or real image, aspect ratio 16:9
  • Content: project name (H3), one-line descriptor (body), "Read Story →" link in --color-accent
  • No shadow
09

Image System

Placeholder Frames

  • Background: --color-placeholder-bg
  • Label text: --color-placeholder-text, centered, 0.85rem Roboto Light
  • Label format: [ Descriptive label of intended image content ]
  • Every placeholder has a specific label — no generic gray boxes

Real Images

  • All images served as WebP with PNG fallback via <picture> element
  • Hero image: loading="eager", fetchpriority="high"
  • All other images: loading="lazy"
  • Intrinsic dimensions set on every <img> to prevent layout shift
  • Hero retina variant: 2560px wide WebP alongside 1800px standard

Lightbox Modal

  • Triggered by clicking any project image
  • Full viewport overlay, rgba(0,0,0,0.9) background
  • Image centered, max 90vw / 90vh
  • Close via × button (top right) or click outside
  • No libraries — vanilla JS in main.js

Image Layout Patterns

  • Full width: single image spanning content column
  • 2-up: two images side by side, equal width, stacks on mobile
  • 3-up: three images side by side, equal width, stacks on mobile
  • 2×2 grid: four images in a two-column grid, stacks to single column on mobile
  • 5-up inline: five images side by side, used for App Store / marketing asset rows
10

Theme System

Implementation

  • Default: light mode
  • Toggle: sets data-theme attribute on <html> element
  • Persistence: localStorage.setItem('theme', value)
  • Flash prevention: inline <script> in <head> reads localStorage and sets data-theme before first paint — eliminates flash on reload

Pre-Paint Script

(function() {
  const saved = localStorage.getItem('theme');
  if (saved) document.documentElement.setAttribute('data-theme', saved);
})();

Rules

  • All color values reference tokens — no hardcoded hex values in components
  • Both themes tested at every breakpoint before shipping
  • No third theme — light and dark only
11

Animation

Scroll Animations

  • API: Intersection Observer — no libraries
  • Primary: fade-up — elements start opacity: 0, translateY(20px), transition to full opacity and position on viewport entry
  • Duration: 400ms
  • Easing: ease-out
  • Stagger: card grids use --reveal-delay CSS custom property, incremented per child (80ms between cards)
  • Hero: sequences in on page load, not scroll

Rules

  • Entry animation only — no exit animations
  • prefers-reduced-motion media query disables all animations
  • No bounce, elastic, or overshoot easing
  • Duration never exceeds 450ms
12

Accessibility

  • Semantic HTML throughout: <header>, <main>, <nav>, <section>, <article>, <footer>
  • All images have descriptive alt text
  • Color contrast meets WCAG AA across both themes
  • Focus states visible on all interactive elements
  • aria-current="page" on active nav items
  • rel="noopener" on all external links
  • prefers-reduced-motion respected by animation system
  • Theme toggle has accessible label

Guiding Principles

  1. Content is the star — design serves writing, never competes with it
  2. Tokens over values — no hardcoded colors or sizes anywhere in components
  3. One file per concern — one stylesheet, one script, no exceptions
  4. No dependency that can break — vanilla stack runs correctly in any browser indefinitely
  5. Constraints clarify — every limitation produced a better decision than freedom would have
